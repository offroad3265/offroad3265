OFFROAD 32 65 — GESTION CENTRALISÉE DES DOCUMENTS — V8.9.24
================================================================

SOURCE UNIQUE
documents-config.js

Pour ajouter un document, créer une nouvelle entrée dans :
window.OFFROAD_DOCUMENTS_CONFIG.documents

PARAMÈTRES
- id : identifiant unique
- ordre : ordre d’affichage
- actif : afficher ou masquer
- titre : libellé principal
- titreCourt : libellé dans le parcours d’inscription
- menu : présence dans tous les menus DOCUMENTS
- pageDocuments : présence sur la page DOCUMENTS
- inscription : présence dans l’étape DOSSIER
- obligatoire : compte dans le dossier complet
- remplissable : document remplissable
- aRenvoyer : doit être retourné au site
- page : page dédiée du document
- fichier : fichier PDF associé
- instructionCourte : consigne propre au document

RÈGLE
Un document ajouté une seule fois dans documents-config.js se propage automatiquement
dans toutes les zones correspondant à ses paramètres.

Les scripts documents-runtime.js génèrent :
- les menus DOCUMENTS
- les boutons du parcours d’inscription
- le nombre de documents requis
- le texte “Dossier complet”
- les sélecteurs de la page DOCUMENTS

IMPORTANT
Pour un nouveau document nécessitant un workflow spécifique de remplissage/renvoi,
créer sa page dédiée sur le même modèle que fiche-individuelle, contrat ou CGV,
puis renseigner cette page dans le champ "page".
