AJOUTER UNE NOUVELLE DATE DE RAID
================================

1. Ouvrir le fichier : dates-raids.js

2. Dans window.OFFROAD_RAIDS = [ ... ], dupliquer un bloc existant.

3. Modifier les 6 informations :
   pays   : maroc / espagne / sardaigne / tunisie
   annee  : ex. 2027
   date   : ex. "12 → 18 AVRIL 2027"
   titre  : nom du raid
   statut : ex. "Places disponibles"
   prix_solo : ex. "2 400 €"
   prix_duo  : ex. "2 800 €"
   lien   : page à ouvrir lorsque l'on clique sur le raid

Exemple :

{
  pays: "maroc",
  annee: 2027,
  date: "12 → 18 AVRIL 2027",
  titre: "Raid Maroc • Atlas & Désert",
  statut: "Places disponibles",
  prix_solo: "2 400 €",
  prix_duo: "2 800 €",
  lien: "maroc-avril-2027.html"
}

Le menu déroulant des années et les cartes de l'accueil se mettent
automatiquement à jour à partir de ce fichier.


IMPORTANT
=========
Si vous ajoutez un nouveau pays, son identifiant doit être identique dans :
- pays-raids.js
- dates-raids.js

Exemple :
id du pays dans pays-raids.js : "portugal"
pays dans dates-raids.js      : "portugal"
