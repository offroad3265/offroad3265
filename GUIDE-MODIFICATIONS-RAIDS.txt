OFFROAD 32 65 — GUIDE DE MODIFICATION DES RAIDS
================================================

Cette version utilise un gabarit programme commun à tous les pays.

POUR MODIFIER UN RAID
- Dates / titre / statut / tarifs / liens : dates-raids.js
- Programme jour par jour : programmes-raids.js
- Présentation / textes / photos : raid-presentations.js si présent
- Prestations : prestations-globales.js ou overrides centralisés

AJOUTER UN JOUR
Ajouter un objet dans la liste jours du raid :
{
  repere: "J3",
  titre: "Titre de l'étape",
  distance: "Environ 180 km",
  texte: "Description..."
}

SUPPRIMER UN JOUR
Supprimer uniquement l'objet correspondant et mettre nb_jours à jour si nécessaire.

AJOUTER UN RAID
Créer une entrée dans dates-raids.js et une entrée correspondante dans programmes-raids.js.
Le gabarit programme s'applique automatiquement.

RÈGLE
Les différences entre raids doivent être exprimées dans les données, pas avec du CSS spécifique à un pays.


RÈGLE AUTOMATIQUE DE DISPOSITION
- Raid de 1 à 3 jours : 1 colonne, jours les uns sous les autres.
- Raid de 4 jours et plus : 2 colonnes.
- Mobile : toujours 1 colonne.
- Le bandeau Distance totale conserve le gabarit universel.
Cette règle est automatique : aucune mise en page spécifique n'est nécessaire lors de l'ajout d'un raid.


RÈGLE V7 — GABARIT PROGRAMME UNIVERSEL
- Tous les pays utilisent exactement le même moteur de programme.
- 1 à 3 jours : 1 colonne.
- 4 jours et plus : 2 colonnes indépendantes sur toute la largeur.
- Espacement horizontal : 12 px.
- Espacement vertical : 12 px.
- Bandeau Distance totale : même gabarit pour tous les raids.
- Mobile : 1 colonne.
- Les différences entre raids doivent venir des données de programmes-raids.js, jamais d'un CSS propre à un pays.
