AJOUTER / MODIFIER LE PROGRAMME D'UN RAID
==========================================

Le fichier dates-raids.js contient les informations générales du raid :
pays, dates, intitulé, prix solo, prix duo, statut et lien programme.

Le fichier programmes-raids.js contient le programme détaillé.

Chaque raid possède un "id" unique. Le même id doit être utilisé
dans dates-raids.js et programmes-raids.js.

Exemple :

Dans dates-raids.js :
id: "espagne-sept-2026"

Dans programmes-raids.js :

"espagne-sept-2026": {
  titre: "Programme Raid Espagne",
  sous_titre: "19 et 20 septembre 2026",
  etapes: [
    {
      jour: "Jour 1",
      titre: "Titre de l'étape",
      texte: "Description du programme..."
    },
    {
      jour: "Jour 2",
      titre: "Titre de l'étape",
      texte: "Description du programme..."
    }
  ]
}

Le bouton "Découvrir le programme" ouvre automatiquement :
programme-raid.html?id=IDENTIFIANT-DU-RAID

Vous pouvez simplement donner le programme à ChatGPT : il l'intégrera
au bon raid sans modifier le design.


AJOUTER UN FILM AU PROGRAMME
============================
Copier le fichier vidéo dans le dossier du site puis ajouter son nom
dans l'entrée du raid dans programmes-raids.js.

Exemple :
video: "film-maroc-2026.mp4"

Le film apparaîtra automatiquement dans la page
"DÉCOUVRIR LE PROGRAMME" du raid concerné.


PAGE FIXE DU PROGRAMME DÉTAILLÉ
===============================
Le bouton "VOIR LE DÉTAIL" de la page vidéo ouvre désormais :
programme-detail.html?id=IDENTIFIANT-DU-RAID

Cette page est fixe sur ordinateur et affiche le programme détaillé du raid.


PHOTO OU VIDÉO DANS « DÉCOUVRIR LE PROGRAMME »
================================================
Chaque raid peut afficher soit une photo, soit une vidéo en grand.

Dans programmes-raids.js :

Pour une vidéo :
media_type: "video",
media: "film-du-raid.mp4",

Pour une photo :
media_type: "image",
media: "photo-du-raid.jpg",

Copier d'abord le fichier dans le dossier du site.

Vous pouvez aussi simplement envoyer la photo ou la vidéo à ChatGPT
et préciser le raid concerné : le média sera intégré au bon programme.


ACCÈS DIRECT AU PROGRAMME
=========================
Le bouton « VOIR LE DÉTAIL » de la page photo/vidéo ouvre directement
la page du programme détaillé renseignée dans le champ :

detail: "nom-de-la-page-programme.html"

S'il n'existe pas encore de programme détaillé pour un raid,
le bouton « VOIR LE DÉTAIL » n'est pas affiché.
