AJOUTER DES PHOTOS OU VIDEOS DANS LA GALERIE
============================================

1. Copier les fichiers photo/vidéo dans le dossier du site.

2. Ouvrir galerie.js

3. Ajouter un bloc par média :

{
  type: "image",
  pays: "maroc",
  annee: 2026,
  raid: "Maroc 2026",
  titre: "Dunes de Merzouga",
  media: "photo-maroc-01.jpg",
  legende: "Raid Maroc 2026"
}

Pour une vidéo :
type: "video"
media: "ma-video.mp4"

Les filtres Pays / Année / Raid se mettent à jour automatiquement.
