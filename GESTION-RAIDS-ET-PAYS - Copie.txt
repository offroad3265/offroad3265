AJOUTER / MODIFIER UNE DATE DE RAID
-----------------------------------
Voir : AJOUTER-UN-RAID.txt
Fichier à modifier : dates-raids.js

Les menus "Nos raids" sont générés automatiquement à partir de pays-raids.js.
Les cartes de l'accueil sont alimentées automatiquement à partir de dates-raids.js.


SYNCHRONISATION
---------------
Le fichier dates-raids.js est maintenant la source unique des raids.
Une date ajoutée ou modifiée dans dates-raids.js alimente automatiquement :
- les cartes Calendrier Raid de la page d'accueil ;
- la page "Nos raids".

Le fichier pays-raids.js reste la source unique pour la liste des pays.
