OFFROAD 32 65 — PAGE PARTENAIRES PARAMÉTRABLE
================================================

SOURCE UNIQUE DES PARTENAIRES
Fichier : contenu-site.js
Bloc : window.OFFROAD_CONTENU.partenaires

AJOUTER UN PARTENAIRE
Ajouter un objet :
{
  id: "identifiant-unique",
  actif: true,
  ordre: 3,
  nom: "Nom du partenaire",
  role: "Rôle / activité",
  logo: "logo.jpg",
  description: "Texte descriptif",
  lien: "https://...",
  bouton: "VISITER LE SITE",
  fond_sombre: false
}

MODIFIER
Changer uniquement le ou les champs concernés.

SUPPRIMER
Supprimer l'objet complet du partenaire.

MASQUER TEMPORAIREMENT
Mettre actif: false.

RÉORDONNER
Modifier la valeur ordre.

LOGO
Modifier le champ logo avec le nom du nouveau fichier image.

LIEN / BOUTON
- lien vide = aucun lien
- bouton vide = aucun bouton
- si lien + bouton sont renseignés, un bouton est ajouté automatiquement.

MISE EN PAGE
La structure validée de la page PARTENAIRES reste inchangée :
- largeur identique à l'accueil
- partenaires en une seule colonne
- un partenaire sous l'autre
- adaptation mobile automatique
