OFFROAD 32 65 — PAGE D'INSCRIPTION PARAMÉTRABLE

La page inscription-raid.html est maintenant pilotée par :
    inscription-config.js

Pour faire évoluer la page sans toucher à la mise en page :
1. Ouvrir inscription-config.js avec un éditeur de texte.
2. Modifier les couleurs dans la section "theme".
3. Modifier les titres dans "labels".
4. Modifier les textes des étapes dans "steps".
5. Modifier les libellés des boutons ou le nom du fichier RIB dans "actions".

IMPORTANT :
- Ne pas supprimer les guillemets ni les virgules.
- Les textes peuvent contenir du HTML simple, par exemple <strong>...</strong>.
- La page conserve son contenu actuel si le fichier de configuration n'est pas chargé.
- Le raid sélectionné, ses dates et ses tarifs restent alimentés automatiquement par dates-raids.js.
